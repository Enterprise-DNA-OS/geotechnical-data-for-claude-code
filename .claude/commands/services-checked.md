---
description: Record the date the underground services were located for a location, before anyone breaks ground.
---

Run `npm run geo -- services-checked --location=<PROJECT/NAME> --on=<date> --actor=NAME --json`.

Confirm the change in one line. Run it with `--dry-run` first when the operator is unsure, and always pass `--actor` with their name.

If the operator has not checked services yet, say plainly that the work should not start until the plans are in hand and the services are marked out.
