---
description: Record a location uploaded to the NZ Geotechnical Database, with its NZGD id.
---

Run `npm run geo -- upload-nzgd --location=<PROJECT/NAME> --id=<NZGD id> --on=<date> --actor=NAME --json`.

Confirm the change in one line. Run it with `--dry-run` first when the operator is unsure, and always pass `--actor` with their name.
