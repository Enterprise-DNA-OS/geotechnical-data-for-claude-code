---
description: Record a piezometer reading (depth to water). Shows when the next one is due.
---

Run `npm run geo -- read-piezo --location=<PROJECT/NAME> --depth=<m> --on=<date> --actor=NAME --json`.

Confirm the change in one line. Run it with `--dry-run` first when the operator is unsure, and always pass `--actor` with their name.
