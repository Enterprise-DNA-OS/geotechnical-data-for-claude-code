---
description: Record the surveyed position and ground level of a location, with the survey method.
---

Run `npm run geo -- set-coords --location=<PROJECT/NAME> --easting=<m> --northing=<m> --level=<m> --method="RTK GPS" --actor=NAME --json`.

Confirm the change in one line. Run it with `--dry-run` first when the operator is unsure, and always pass `--actor` with their name.
