---
description: Record a piezometer, monitoring well or inclinometer installed in a location, with screen depths and how often it is read.
---

Run `npm run geo -- install --location=<PROJECT/NAME> --kind="standpipe piezometer" --top=<m> --base=<m> --on=<date> --every=<days> --actor=NAME --json`.

Confirm the change in one line. Run it with `--dry-run` first when the operator is unsure, and always pass `--actor` with their name.
