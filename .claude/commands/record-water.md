---
description: Record a groundwater strike, a standing level, or that groundwater was not encountered.
---

Run `npm run geo -- record-water --location=<PROJECT/NAME> --kind=<strike|standing|not encountered> --depth=<m> --on=<date> --actor=NAME --json`.

Confirm the change in one line. Run it with `--dry-run` first when the operator is unsure, and always pass `--actor` with their name.
